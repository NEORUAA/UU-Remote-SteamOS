# Сборка и повторное использование реле

Установщик собирает фиксированный FreeRDP SDL с исправлениями Plus для буфера и размера. [Рецепт](../../../vendor/freerdp-sdl-build/), [фиксация источников](../../../vendor/freerdp-sdl-build/source-lock.json), [профиль](../../../patches/freerdp-sdl-product.json) описывают ревизии, архивы, инструменты и 13 файлов Windows.

<a id="reference-toolchain"></a>

## Подготовка эталонных инструментов Ubuntu 26.04

В Ubuntu 26.04 amd64 [скрипт подготовки](../../../scripts/prepare-build-toolchain.py) загружает 17 фиксированных официальных пакетов Ubuntu и сверяет 14 файлов компилятора и инструментов с `source-lock.json`. [Манифест пакетов](../../../patches/reference-build-packages.json) содержит версии, размеры и хеши. Скрипт загружает, распаковывает в отдельный личный каталог и проверяет файлы, не устанавливая системные пакеты. Запускайте из корня репозитория:

```bash
python3 scripts/prepare-build-toolchain.py \
  --packages-dir "$HOME/.cache/uu-plus/reference-packages" \
  --root "$HOME/.cache/uu-plus/reference-root"
```

`--packages-dir` задаёт кэш пакетов, а `--root` — новый или пустой личный каталог. Для повторной распаковки и проверки только из кэша выберите другой пустой каталог и добавьте `--verify-only`; доступ к сети не используется:

```bash
python3 scripts/prepare-build-toolchain.py \
  --packages-dir "$HOME/.cache/uu-plus/reference-packages" \
  --root "$HOME/.cache/uu-plus/reference-root-offline" \
  --verify-only
```

Скрипт выводит команду `sudo apt install` со всеми 17 локальными путями `.deb`. Выполните её вручную в Ubuntu 26.04, чтобы установить эталонные инструменты. Рецепт читает фиксированные пути `/usr`; личный каталог распаковки служит для проверки, а не для выбора среды сборки.

Затем запустите обычный установщик. Он подготовит остальные зависимости сборки хоста, WineHQ и пакеты среды GNOME, выполнит существующую сборку реле и проверит результат перед развёртыванием. Подготовка проверяет 14 эталонных файлов; полная сборка и её 13 файлов среды проверяются следующим процессом:

```bash
./install.sh
./scripts/verify.sh --quick
```

В Ubuntu 24.04 используйте существующий проверенный результат, соответствующий текущему профилю, через описанное ниже повторное использование. Приведённые пакеты Ubuntu 26.04 предназначены для 26.04.

## Сборка и кэш

Для сборки из свежих исходников нужны точные проверенные файлы компилятора и инструментов из `source-lock.json`, с теми же байтами. Обычные APT-пакеты дистрибутива не предоставляют эту цепочку автоматически.

`./install.sh` готовит пакеты и проверяет реле до замены. `build/freerdp` используется при совпадении происхождения с профилем/рецептом/фиксированными файлами. Иначе `scripts/build-winpr.sh` собирает свежие источники двумя заданиями с пределом 900 секунд и проверяет результат.

Когда проверенные инструменты установлены по путям `/usr` из рецепта и зависимости сборки готовы, можно также собрать отдельный кэш реле:

```bash
UURB_BUILD_DIR=/absolute/path/to/build-work   ./scripts/build-winpr.sh /absolute/path/to/fresh-output
```

Выберите новый выходной каталог. Уникальная исходная задача создаётся под рабочим каталогом, без использования работающего Wine prefix. Повторно использовать проверенную сборку:

Из корня репозитория сначала проверьте существующий результат на соответствие текущему профилю. Обычный установщик готовит зависимости хоста. Используйте `--skip-packages` только при уже установленных инструментах совместимости, WineHQ и пакетах среды GNOME; `--skip-account-login` допустим для настроенной учётной записи.

```bash
python3 scripts/verify-freerdp-runtime.py --mode build /absolute/path/to/verified/output
```

Затем повторно используйте его через существующий вход установщика:

```bash
UURB_FREERDP_PREBUILT_DIR=/absolute/path/to/verified/output   ./install.sh
```

Нужны совпадающие рецепт, файлы и происхождение текущего профиля. Изменение профиля требует повторного запуска сборки/проверки; правка квитанции или сумм не одобряет другие бинарные файлы. Перед службой проверяется и скопированный runtime.

## Входные данные и результаты

Зафиксированы FreeRDP/WinPR, SDL 3.2.28, SDL_ttf, OpenH264, FreeType, HarfBuzz, OpenSSL/cJSON/uriparser. До сборки проверяются патч и хэши MinGW/компилятора/инструментов. Изменения требуют пересмотра рецепта.

Карты префиксов файлов/макросов/отладки нормализуют пути. FreeRDP opaque — OFF с первого конфигурирования, DLL совместимости имеет относительное имя выхода. Локальные пути не попадают в результат.

Два разных исходных/выходных корня дали одинаковые байты всех 13 файлов. Первый/повторный CMake дал одинаковые метаданные. Полная чистая сборка без готового runtime заняла около 700 секунд из 900 и прошла проверки runtime/происхождения. См. [качество](quality-guide.md), [затраты](performance-evidence.md).
