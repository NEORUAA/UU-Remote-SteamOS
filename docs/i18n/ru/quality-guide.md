# Качество, разрешение и частота кадров

Выберите холст на Ubuntu, затем качество передачи на управляющем компьютере или телефоне. Размер, сжатие, запрошенные FPS и предел битрейта задаются отдельно.

## Выбор холста

Откройте **UU Remote 画质与分辨率** в GNOME или выполните:

```bash
uu-remote quality gui
uu-remote quality list
uu-remote quality status
uu-remote quality apply 2160p
uu-remote quality guide
```

![Выбор четырёх разрешений](../../images/quality-presets.png)

| Режим | Холст | Применение |
| --- | --- | --- |
| `720p` | 1280 × 720 | Маленький экран или ограниченная связь |
| `1080p` | 1920 × 1080 | Повседневная работа; исходный выбор |
| `1440p` | 2560 × 1440 | Больше пространства, меньше пикселей, чем 4K |
| `2160p` | 3840 × 2160 | Мелкий текст и полный рабочий стол 4K |

Переустановка сохраняет выбор. Умное масштабирование вмещает весь исходный стол и преобразует координаты указателя по той же геометрии. Разрешение и пропорции источника влияют на изображение. Физический экран GNOME не меняется; захват может обрабатывать весь источник.

Программа различает сохранённый стартовый/запрошенный RDP размер и текущий холст. Изменение сохранённого размера кратко переподключает UU. Повторное применение сохранённого режима восстанавливает живой холст на поддерживаемом RDP-пути без перезапуска реле и проверяет размер. Перед изменением запускается таймер отката: если мост не готов, возвращаются прежние настройки. Дождитесь окончания восстановления.

Фиксированные режимы используют стандартное `--follow-desktop-resolution off`. Если следование включали, сначала отключите. См. [установку](../../../i18n/README.ru.md), `./install.sh --help`. Увеличение проверенного источника 4K до 5K выглядело хуже на Mac без новых деталей, поэтому обычный максимум — 4K. Номинальные 60 Hz относятся к виртуальному дисплею; реальные FPS зависят от всей связи.

## Настройки управляющего устройства

Компьютер: **控制中心 → 画质**. Телефон: **操作 → 显示**. True Color также выбирается на контроллере при поддержке.

![Штатное меню UU](../../images/uu-native-quality-menu.png)

Пример получен при управлении Mac с Ubuntu. Устройства и кодек определяют варианты. Качество меняет сжатие/детали, FPS — запрошенную частоту. True Color улучшает цветной текст и границы. При ограничении производительности выберите доступный уровень. Сравнивайте одинаковый текст и движение.

Документация NetEase: [FPS / Super Screen](https://uuyc.163.com/help/superscreen.html) · [True Color](https://uuyc.163.com/features/color/) · [UU](https://uuyc.163.com/help/20241216/40221_1200122.html). Super Screen/виртуальный драйвер в Wine и 144 FPS ещё не проверены. См. [измерения](performance-evidence.md).

## Предел битрейта

```bash
uu-remote quality bitrate 20
uu-remote quality bitrate 0
```

`20` запрашивает максимум **20 Mbps**, `0` отменяет предел. Целевой битрейт, FPS и размер не задаются. Смена режима сохраняет предел. Слишком низкий может ухудшить детали движения.

## Курсор и действия рабочего стола

Необязательная защита курсора при новой установке выключена. Если указатель слишком велик:

```bash
./install.sh --skip-packages --skip-account-login --cursor-guard on --cursor-size 24
```

`--cursor-size auto` следует настройкам стола; фиксированный диапазон — 24–128 пикселей. Настройки GNOME/приложений независимы. Dock использует GNOME. Android «показать рабочий стол/все окна» связан со столом/обзором GNOME; реальные кнопки ожидают проверки.

## Управление и восстановление

`uu-remote open` открывает отдельный просмотрщик. Увеличить его:

```bash
UURB_WINDOW_SCALE=2 ./install.sh --skip-packages --skip-account-login
```

Масштабы: `1` по умолчанию, `1.5`, `2`, `3`. Это только просмотрщик, не DPI Wine/разрешение. Его буфер изолирован, обычное копирование использует реле.

```bash
uu-remote status
uu-remote quality status
uu-remote network
uu-remote logs
```

Пользовательская служба перезапускает сбойные компоненты, иногда с переподключением. Откат режимов восстанавливает настройки; развёртывание имеет отдельную процедуру. [Устранение неполадок](troubleshooting.md), [сборка](source-build.md). Исходящее управление через Wine имеет другие ограничения качества. Монитор/виртуальные выходы: [Ubuntu 26.04](ubuntu-26.04-port.md), ещё проверить. Телефон → ToDesk → Mac → UU всё ещё повторяет текст; прямой ввод работает.
