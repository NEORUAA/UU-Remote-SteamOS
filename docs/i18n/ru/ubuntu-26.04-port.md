# Ubuntu 26.04 и GNOME 50

Plus расширяет [MIT-мост Lachlan Chen](https://github.com/lachlanchen/uu-remote-ubuntu-bridge) на x86-64 Ubuntu 26.04/GNOME 50, сохраняя24.04/GNOME 46. Основа: изоляция Wine, проверенные манифесты, брокер, реле и служба.

Для установки реле нужна точная проверенная цепочка инструментов или уже проверенный результат; обычные APT-пакеты не предоставляют эту цепочку автоматически. См. [условия сборки и использование кэша](source-build.md).

| Компонент | Исходный проект | Plus |
| --- | --- | --- |
| Ubuntu |24.04|24.04/26.04; прочие: `UURB_ALLOW_UNVALIDATED_UBUNTU=1`|
| Windows UU |4.33.0.8907|Одобрен4.42.0.2770; старые манифесты доступны|
| libei |Изолированный backport1.2.1|Исправленная системная библиотека, иначе backport|
| Реле |Фиксированный nightly SDL/WinPR|Патчи фиксированной сборки, [сборка](source-build.md)|
| CI |24.04|24.04/26.04; результат по запуску|

Наблюдаемая установка: GRD 50.2/libei 1.5.0. Для старых библиотек есть `ee27dd5c92e4e9496a36ca2d4112049fe02d2269`. `UURB_LIBEI_MODE=system|backport` хранит выбор, `verify.sh` проверяет загрузку. WineHQ stable.

## Поведение

Четыре режима, полный стол и координаты. Новая установка1080p, обновление сохраняет настройки. Новая сохранённая величина переподключает с откатом; повторная восстанавливает холст. Пользователь подтвердил обычное соединение и штатный максимум4K. Новый RDP — `rdp-public`, обновление хранит путь. Unicode/физические клавиши отдельно. Менеджер/окна захватываются отдельно; закрытие просмотрщика возвращает фокус реле, менеджер остаётся отображённым. Буфер рабочего стола активен, менеджера изолирован.

| Функция | Результат |
| --- | --- |
| Прямой китайский телефон/Mac |Подтверждён при интеграции|
| Текст копировать/вставить |Пользователь подтвердил|
| Обновление Mac UU |Переподключение/китайский/вставка нормальны,4K похож|
| Перекрытие/фокус менеджера |Решено по отзыву, выборочные проверки нормальны|
| Android |Backend в обе стороны, кнопки ещё проверить|
| Курсор |Тема/часть проверена, все формы ещё проверить|
| Монитор/виртуальный выход |На этом хосте ещё проверить|
| Телефон→ToDesk→Mac→UU |Повтор`a` не решён|

VNC/FreeRDP/Openbox запускаются с локальными CJK-шрифтами/DPI/учётными данными. Dock настраивает GNOME. Исходящее качество/физическое разрешение отделены от входящего холста. [Качество](quality-guide.md), [архитектура](architecture.md), [сравнение](upstream-comparison.md).

## Обновления

Сохраните Plus как `origin`:

```bash
git remote add upstream https://github.com/lachlanchen/uu-remote-ubuntu-bridge.git
git fetch upstream
```

Проверяйте изменения в рабочей ветке. После runtime-изменений:

```bash
./install.sh --skip-packages --skip-account-login
./scripts/verify.sh --quick
```

Установка кратко прерывает соединение; digest показывает изменения до переустановки. [Повторяемое обновление](reusable-upgrade.md) описывает runtime, откат режима — размер. Неизвестный хэш UU блокирует автоматический патч; новая версия требует смыслового анализа, манифеста и runtime-проверки: [сопровождение](../../upstream-maintenance.md). Распространяются MIT-источники/манифесты, лицензии UU/зависимостей сохраняются.
