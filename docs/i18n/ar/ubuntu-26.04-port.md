# Ubuntu 26.04 وGNOME 50

يوسع Plus [جسر Lachlan Chen المرخص MIT](https://github.com/lachlanchen/uu-remote-ubuntu-bridge) إلى x86-64 Ubuntu 26.04/GNOME 50، مع الاحتفاظ بـ24.04/GNOME 46. عزل Wine والبيانات المدققة والوسيط والمرحّل والخدمة هي الأساس.

يتطلب تثبيت المرحّل سلسلة الأدوات المراجعة المطابقة أو إخراجًا موثّقًا موجودًا؛ حزم APT المعتادة لا توفر تلك الأدوات تلقائيًا. راجع [متطلبات البناء وإعادة استخدام النسخة المخبأة](source-build.md).

| المكون | المشروع الأصلي | Plus |
| --- | --- | --- |
| Ubuntu |24.04|24.04/26.04؛ غيرهما يتطلب `UURB_ALLOW_UNVALIDATED_UBUNTU=1`|
| Windows UU |4.33.0.8907|4.42.0.2770 المعتمد والبيانات السابقة المتاحة|
| libei |Backport1.2.1 معزول|مكتبة النظام المصححة، وإلا backport|
| المرحّل |SDL nightly وWinPR مثبتان|مصدر ثابت مصحح؛ [البناء](source-build.md)|
| CI |24.04|24.04/26.04؛ نتائج كل تشغيل|

التثبيت الملاحظ يستخدم GRD 50.2 وlibei 1.5.0. توجد للمكتبات القديمة المراجعة `ee27dd5c92e4e9496a36ca2d4112049fe02d2269`. يحفظ `UURB_LIBEI_MODE=system|backport` الاختيار ويتحقق `verify.sh` من المكتبة المحملة. Wine من WineHQ stable.

## الاستخدام

أربعة أحجام وصورة كاملة وإحداثيات متوافقة. التثبيت الجديد1080p والتحديث يحفظ الإعداد. تغيير الحجم المحفوظ يعيد الاتصال مع تراجع؛ تطبيقه مجددًا يستعيد المساحة الحالية. أكد المستخدم الاتصال والقائمة الأصلية حتى4K. RDP الجديد `rdp-public`، والتحديث يحفظ المسار. Unicode والمفاتيح الفعلية منفصلان. تُلتقط الإدارة والنوافذ المنبثقة وحدها؛ الإغلاق يعيد التركيز للمرحّل مع بقاء الإدارة مهيأة للعرض. حافظة سطح المكتب فعالة والإدارة معزولة.

| الميزة | النتيجة |
| --- | --- |
| الصينية مباشرة من الهاتف/Mac |أكدها المستخدم أثناء التكامل|
| نسخ النص ولصقه |طبيعي حسب المستخدم|
| تحديث Mac UU |الاتصال والصينية واللصق طبيعي،4K مشابه|
| تداخل الإدارة والتركيز |حل حسب المستخدم، فحوص مختارة طبيعية|
| Android |الخلفية تعمل في الاتجاهين، الأزرار تنتظر|
| المؤشر |السمة وبعض الفحوص طبيعية، كل الأشكال تنتظر|
| الشاشة والمخرج الافتراضي |ينتظران على هذا الجهاز|
| الهاتف→ToDesk→Mac→UU |تكرار`a` لم يحل|

مشغلات VNC/FreeRDP/Openbox تضبط خطوط CJK وDPI وبيانات الدخول محليًا. Dock يخص GNOME. الجودة الصادرة والدقة الفعلية تختلفان عن مساحة الاستقبال. [الجودة](quality-guide.md)، [البنية](architecture.md)، [المقارنة](upstream-comparison.md).

## التحديث

احتفظ بـPlus بوصفه `origin`:

<div dir="ltr">

```bash
git remote add upstream https://github.com/lachlanchen/uu-remote-ubuntu-bridge.git
git fetch upstream
```

</div>

راجع الأصل في فرع تطوير. بعد تغيير بيئة التشغيل:

<div dir="ltr">

```bash
./install.sh --skip-packages --skip-account-login
./scripts/verify.sh --quick
```

</div>

التثبيت يقطع الاتصال قليلًا؛ ملخص المصدر يشير للتغيير حتى إعادة التثبيت. [التحديث القابل للتكرار](reusable-upgrade.md) يعالج التشغيل والتراجع يعالج الحجم. بصمة UU غير المعروفة توقف الرقع التلقائية؛ النسخة الجديدة تتطلب مراجعة المعنى وبيانات اعتماد وفحوصًا: [الصيانة](../../upstream-maintenance.md). يُوزع مصدر MIT والبيانات، وتحتفظ UU والتبعيات برخصها.

</div>
