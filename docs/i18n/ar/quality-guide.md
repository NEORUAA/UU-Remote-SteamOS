# الجودة والدقة ومعدل الإطارات

اختر مساحة الصورة على Ubuntu ثم اضبط جودة البث على الكمبيوتر أو الهاتف المتحكم. الحجم والضغط ومعدل FPS المطلوب وحد البتات إعدادات مستقلة.

## اختيار مساحة الصورة

افتح **UU Remote 画质与分辨率** في GNOME أو نفّذ:

<div dir="ltr">

```bash
uu-remote quality gui
uu-remote quality list
uu-remote quality status
uu-remote quality apply 2160p
uu-remote quality guide
```

</div>

![اختيار أربع درجات للدقة](../../images/quality-presets.png)

| الخيار | المساحة | الاستخدام |
| --- | --- | --- |
| `720p` | 1280 × 720 | شاشة صغيرة أو اتصال محدود |
| `1080p` | 1920 × 1080 | العمل اليومي والقيمة الافتراضية للتثبيت الجديد |
| `1440p` | 2560 × 1440 | مساحة عمل أكبر ببكسلات أقل من 4K |
| `2160p` | 3840 × 2160 | نص دقيق وسطح مكتب 4K كامل |

إعادة التثبيت تحفظ الاختيار. التحجيم الذكي يضم سطح المكتب المصدر كاملًا ويحوّل إحداثيات المؤشر وفق الهندسة نفسها. دقة المصدر ونسبته تؤثران في الصورة. المساحة لا تغيّر شاشة GNOME الفعلية، وقد يستمر الالتقاط في معالجة المصدر كاملًا.

يفصل المحدد بين الحجم المحفوظ لبدء التشغيل/RDP والمساحة الحالية. تغيير الحجم المحفوظ يعيد اتصال UU لفترة قصيرة. إعادة تطبيق الخيار المحفوظ تستعيد المساحة مباشرة عبر مسار RDP المدعوم دون إعادة تشغيل المرحّل، وتتحقق من الحجم. يبدأ مؤقت تراجع قبل التغيير ويعيد الإعداد السابق إن لم يصبح الجسر جاهزًا. انتظر اكتمال الاستعادة قبل تغيير آخر.

الخيارات الثابتة تستخدم افتراضيًا `--follow-desktop-resolution off`. إن فعّلت تتبع دقة المصدر فأوقفه أولًا. راجع [التثبيت](../../../i18n/README.ar.md) و`./install.sh --help`. تكبير المصدر 4K المجرّب إلى 5K لم يضف تفاصيل وبدا أسوأ على Mac، لذا تنتهي الخيارات المعتادة عند 4K. قيمة 60 Hz الاسمية تخص الشاشة الافتراضية؛ معدل البث الفعلي يعتمد على الاتصال كله.

## جودة الجهاز المتحكم

الكمبيوتر: **控制中心 → 画质**. الهاتف: **操作 → 显示**. يُختار True Color كذلك على المتحكم عندما يكون متاحًا.

![قائمة جودة UU الأصلية](../../images/uu-native-quality-menu.png)

المثال من Ubuntu يتحكم في Mac. الأجهزة والترميز تحدد الخيارات. الجودة تضبط الضغط والتفاصيل، وFPS معدل التحديث المطلوب. True Color قد يحسن النص الملون والحواف. إذا أبلغ UU عن حد لأداء الجهاز، اختر مستوى متاحًا وقارن النص والحركة نفسيهما.

وثائق NetEase: [FPS / Super Screen](https://uuyc.163.com/help/superscreen.html) · [True Color](https://uuyc.163.com/features/color/) · [UU](https://uuyc.163.com/help/20241216/40221_1200122.html). Super Screen وبرنامج الشاشة الافتراضية في Wine و144 FPS تحتاج إلى اختبار. راجع [القياس](performance-evidence.md).

## حد معدل البتات

<div dir="ltr">

```bash
uu-remote quality bitrate 20
uu-remote quality bitrate 0
```

</div>

`20` يطلب سقف **20 Mbps** و`0` يزيله. لا يضبط معدلًا مستهدفًا ولا FPS ولا الحجم. تغيير الدقة يحفظ هذا الإعداد. الحد الضيق قد يخفض تفاصيل المشاهد المتحركة.

## المؤشر وأفعال سطح المكتب

حماية المؤشر اختيارية ومعطلة عند التثبيت الجديد. إذا كان المؤشر كبيرًا:

<div dir="ltr">

```bash
./install.sh --skip-packages --skip-account-login --cursor-guard on --cursor-size 24
```

</div>

`--cursor-size auto` يتبع حجم سطح المكتب؛ القيم الثابتة 24–128 بكسل. إعدادات GNOME والتطبيقات مستقلة. الشريط Dock يتبع GNOME. أفعال Android لإظهار سطح المكتب وكل النوافذ مرتبطة بسطح GNOME ونظرته العامة؛ الأزرار الفعلية تنتظر الاختبار.

## الإدارة والاستعادة

`uu-remote open` يفتح عارض الإدارة المنفصل. لتكبيره:

<div dir="ltr">

```bash
UURB_WINDOW_SCALE=2 ./install.sh --skip-packages --skip-account-login
```

</div>

المقاييس `1` افتراضيًا و`1.5` و`2` و`3`. يتغير العارض فقط، لا DPI في Wine ولا دقة سطح المكتب. حافظة الإدارة معزولة؛ النسخ العادي يستخدم المرحّل.

<div dir="ltr">

```bash
uu-remote status
uu-remote quality status
uu-remote network
uu-remote logs
```

</div>

تعيد خدمة المستخدم تشغيل المكونات المتعطلة، مع احتمال إعادة اتصال قصيرة. تراجع الخيارات يستعيد الإعدادات؛ نشر بيئة التشغيل له إجراء منفصل. راجع [استكشاف الأعطال](troubleshooting.md) و[البناء](source-build.md). التحكم الصادر من Wine له حدود جودة أخرى. انتقالات الشاشة الفعلية والمخارج الافتراضية تنتظر اختبار هذا الجهاز: [Ubuntu 26.04](ubuntu-26.04-port.md). مسار الهاتف → ToDesk → Mac → UU ما زال يكرر النص؛ الاتصال المباشر يعمل.
