# 键盘兼容性检查

同一控制端的实体键、手机输入法、语音提交和剪贴板粘贴可能走不同路径。遇到某一输入法表现不同，按下面的方法分别比较。

## 记录当前设置

在私有记录中写明主机系统、桌面会话、UU 与控制端版本、键盘布局及输入路由。使用 `uu-remote quality status` 查看画布，再检查保存的桥接设置，公开反馈只给必要选项。

`UURB_TEXT_KEY_DELAY_MS` 是手机文字节奏；实体键延迟和键盘路由是另外两项设置。重新安装会保留原值，调整前先记下自己的设置。参考 [自适应键盘中继](adaptive-keyboard-relays.md) 与 [输入行为版本线](release-tracks.md)。

## 分别检查实际输入方法

打开临时文本接收框，使用无敏感内容的样例 `abcXYZ123,.!?`，比较预期与实际文字：

- 电脑键盘、组合键与快捷键。
- 手机英文与中文输入法。
- 语音提交和多行粘贴。
- 普通文本的双向复制粘贴。
- 新连接与断开后的重连。

先确认目标应用和焦点。若文字进入另一窗口，先修正测试目标。代理接收的事件数量与应用实际收到的文字分别观察，诊断只记录类别、路由、结果数量和错误信息；输入内容及剪贴板内容留在私有环境。

一次只改一项路由或节奏，保留原值，从真实控制端重新比较。交付情况不明确时，不自动重发事件，以免后到的原事件造成重复。XRDP 卡住时按 [XRDP 与键盘恢复](xrdp-and-keyboard-recovery.md) 的顺序处理。公开报告保留版本、设置和脱敏症状，完成的原始记录不要提交到仓库。
