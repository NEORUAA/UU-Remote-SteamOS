# v0.1.0 — 首个受支持交付版本

上游历史发布说明。当前 Plus 安装请见[首页](../../../../i18n/README.zh-Hans.md)。

发布日期：2026-07-17。

这是 UU Remote Ubuntu Bridge 的首个标签版本，将已验证 Ubuntu 桌面中继、手机键盘修正、无人值守启动和生命周期改进整理成可重复更新点。

## 适用安装

基于 `8a68200` 或更早提交的安装应更新，尤其是手机键盘重复 `d` 等字母、数字变成句点的情况。电脑键盘面板仍可能正常，因为它走另一条输入路径。

## 版本环境

| 组件 | 本次支持 |
| --- | --- |
| 主机 | x86-64 Ubuntu24.04 |
| 桌面 | GNOME46，Wayland／Xorg／XRDP |
| UU | 仅`4.33.0.8907` |
| Wine | WineHQ stable11 |
| 桥接 | `v0.1.0` |

未知 UU 可执行文件会被安装器拒绝，不会套用旧二进制修改。

## 手机键盘规范化

手机原生键盘发送成对 `KEYEVENTF_UNICODE` Windows事件。Wine将其作为不合适的物理扫描码交给SDL FreeRDP，导致重复字母和标点。钩子改为将每个Unicode批次直接交给普通用户代理；代理用 `VkKeyScanW` 映射字符、发送普通虚拟按键组合，整批成功才返回原事件数。

硬件按键路径保持。诊断仅标识规范化批次，不记录字符值。

## 无人值守与生命周期

- 用户 `default.target` 启动桥接。
- 可选GDM自动登录通过TPM2加密systemd凭据解锁Keyring。
- 运行时发现GNOME Shell显示、Wayland socket、D-Bus。
- 服务替换后重新注入兼容DLL并准备账号。
- 关键中继退出时systemd重建完整中继。
- Wine清理限于独立UU前缀。

## 当时验证

28项无厂商二进制测试本地与GitHub Actions通过。16事件实时Unicode批次规范化后返回原数且 `error=0`。本地RDP在GNOME文本框精确显示 `aZ0.,!?`。完整验证保持同一UU PID270秒，补丁、进程、账号、代理、RDP检查通过。

## 更新直接克隆

公开仓库无需GitHub认证：

```bash
cd ~/Projects/uu-remote-ubuntu-bridge
git status --short
git fetch --tags origin
git checkout v0.1.0
./install.sh --skip-packages --skip-account-login
./scripts/verify.sh --quick
```

`git status --short` 有修改时，先保存再切标签。安装短暂停止UU、重建兼容组件、保留Wine前缀与账号、重启检查。中继端口、尺寸、显示、Keyring、无人值守配置保留。

## 操作验收

安装后手机重新连接，用普通手机键盘输入：

```text
abcXYZ123,.!?
```

确认代理成功规范化：

```bash
log="$HOME/.local/share/wineprefixes/uu-remote/drive_c/users/$USER/Temp/uu-input-broker.log"
tail -80 "$log" | rg 'text=normalized .*result=[1-9][0-9]* error=0'
```

`./scripts/verify.sh` 另执行270秒稳定检查。

## 已知限制

手机文本只验证当前Wine键盘布局可表示的英文字符；不可表示字符明确失败。无人值守可选，GDM自动登录让物理访问者可进入桌面。普通RDP剪贴板启用；仓库不含网易可执行文件或专有预构建产物。

## 回退

恢复旧源码并重装：

```bash
cd ~/Projects/uu-remote-ubuntu-bridge
git checkout 8a68200
./install.sh --skip-packages --skip-account-login
./scripts/verify.sh --quick
```

回退会恢复旧行为，也恢复原手机键盘已知缺陷，不删除账号。彻底卸载才使用 `./uninstall.sh --dry-run`、`./uninstall.sh`。
