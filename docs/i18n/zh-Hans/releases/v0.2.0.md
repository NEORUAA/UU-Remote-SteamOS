# v0.2.0 — 向后兼容整合版本

上游历史发布说明。当前 Plus 安装请见[首页](../../../../i18n/README.zh-Hans.md)。

发布日期：2026-07-18。

本版将精确v0.1.0输入回退与后续稳定性、隐私诊断、可选调优合并。旧版继续保留在不可变 `v0.1.0` 标签。

## 兼容约定

- 普通鼠标／物理键优先调用UU原始 `SendInput`，失败才用普通用户代理。
- v0.1.0升级保留手机文字间隔0毫秒，新装默认8毫秒。
- 物理按键间隔默认0，调节需主动选择。
- 物理路径默认 `rdp`，直接X11需主动选择。
- 网络过滤默认 `all`，即不筛选。
- 保存端口、尺寸、显示、Keyring、Wine前缀、UU登录、无人值守选择均保留。
- 未知UU可执行文件继续拒绝。

工作正常的旧主机可留在v0.1.0，升级也不会自动采用其他主机的X11路径或延迟设置。

## 扩展路径

提供有界文字／物理按键节奏，不重试或合成按键；可选原生X11/XTEST绕过已确认丢失的Wine/FreeRDP末段；代理确认前核对前台焦点；文字、键盘、鼠标等独立无内容计数；libei keymap描述符修正与有界GNOME RDP保护；默认关闭、失败时放行的进程局部网络选择；运行摘要与XRDP恢复说明。

## 安装或升级

```bash
cd ~/Projects/uu-remote-ubuntu-bridge
git status --short
git fetch --tags origin
git switch --detach v0.2.0
./install.sh --skip-packages --skip-account-login
./scripts/verify.sh --quick
```

有本地修改时先停止切换。安装短暂重启桥接，不删除前缀或要求重新UU登录。

需要主机专用物理间隔时：

```bash
./install.sh --skip-packages --skip-account-login \
  --physical-key-delay-ms 8
```

`0`恢复基础行为；跨机器先测再采用。

代理报告物理调用成功、Xorg/XRDP快速输入仍缺字时，可只绕过最后RDP键盘段：

```bash
./install.sh --skip-packages --skip-account-login \
  --keyboard-route x11 --physical-key-delay-ms 0
./scripts/verify.sh --quick
```

画面、鼠标、剪贴板、手机文字仍走兼容中继。辅助程序只监听回环、每次启动新令牌、断开释放按键、纳入原服务监督。不支持事件先检查再回RDP，部分失败不重放。`--keyboard-route rdp`立即回退，`auto`仅在发现X11目标时选择X11。

## 当时验证

- 40项源码、shell、文档、迁移、原生构建测试通过。
- 独立Xvfb/XTEST顺序交付58事件：29按下、29释放，含Ctrl、Enter。
- 真实直连抽样 `route=x11` 的256次物理调用，全数返回请求事件且 `error=0`；操作者反馈很流畅、旧丢失几乎消除。
- 源码仍先原始调用再代理，安装测试要求物理间隔0、网络选择all。
- 迁移测试要求旧环境文字间隔0。
- 某直接X11主机采用x11、手机8毫秒、无物理延迟；仓库默认仍rdp／0。

## 回退

旧版完整保留：

```bash
git fetch --tags origin
git switch --detach v0.1.0
./install.sh --skip-packages --skip-account-login
./scripts/verify.sh --quick
```

回退替换桥接组件、保留账号与前缀。v0.1.0不理解新调优字段，后续重装v0.2.0会从持久环境重新读取。
