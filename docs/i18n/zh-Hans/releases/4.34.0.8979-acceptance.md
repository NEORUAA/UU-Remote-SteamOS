# UU Remote 4.34.0.8979 已撤回验收记录

此页保留最初支持4.34.0.8979晋升的记录。2026-07-27，生产前缀未通过后续冷启动检查，验收被撤回。二进制补丁仍获静态批准；清单有意不含 `acceptance`，须重新通过完整停止前缀的冷启动与信令检查才可自动晋升。厂商二进制、原始日志、账号、令牌、设备标识、主控地址、桌面内容保留本地。

## 静态审核

4.33与4.34通过语义字符串、RIP相对引用、完整周边控制流、定点 `objdump` 与精确 `xxd` 字节对照。构造默认值保持精确偏移匹配；设置加载、读取、运行时设置保留行为，仅布局与调用位移改变。替换只强制选择已有用户态输入，周边调用及控制流不变。清单保存四处完整原始／替换字节。

6. 补丁服务与审核健康监视器备份通过检查。

## 主控与稳定性

临时4.34通过短期canary桥接启动，原4.33保持不动。服务报告正确版本并建立UU通道，FreeRDP连接3391的GNOME RDP；主控断开重连、控制及剪贴板通道成功。无内容代理记录六次成功鼠标注入。同一服务／中继PID保持297秒，无崩溃转储、强制退出、重注入或 `devcon` 停滞。第二次检查通过清单、二进制、健康监视器、钩子、代理、键盘、账号及主控历史。

canary有四项预期基础设施差异：生产服务未启用、临时单元直接用源码、描述符限额不同、临时GNOME设置不同。实时套接字、明确RDP端口和描述符计数正常；正常生产安装会消除这些差异。

## 撤回原因

canary覆盖已运行的暖路径，没有覆盖下一次生产冷启动。晋升后服务停在 `update_gvinput`，主控显示寻找路由。原子恢复完整4.33快照，XRDP PID不变；冷启动4.33也重现扫描，最终定位共享原因：527个失败 `gvinput` 根和21,894条Wine蓝牙设备记录。

前缀注册表清理将扫描降至8–9毫秒并恢复4.33信令。4.34需在清理启用、前缀完全停止后重测。重新验收要求最新日志达到 `update_gvinput end` 和 `room_state_changed: created`，真实主控重连／输入、登录保留及正常稳定间隔。
