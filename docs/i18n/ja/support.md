# UU Remote Ubuntu Plus を応援する

**コーヒー一杯で応援していただけるとうれしいです ☕**

UU と Ubuntu の更新に合わせて、Plus の対応も続けていきます。応援は新バージョンの検証、開発ツールやトークンの費用を支え、文字入力、コピー＆ペースト、画質をさらに磨く力になります。
